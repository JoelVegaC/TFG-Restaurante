## 📘 Descripción del Modelo
La base de datos incluye las siguientes entidades principales:
- Clientes  
- Reservas  
- Mesas  
- Productos  
- Categorías  
- Pedidos  
- Líneas de pedido 
- Inventario 

Relaciones clave:
- Un cliente puede tener varias reservas.  
- Un pedido contiene múltiples líneas de pedido.  
- Los productos pertenecen a una categoría.
