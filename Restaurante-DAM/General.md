# Proyecto TFG DAM – Sistema de Gestión para Restaurante

Este proyecto forma parte del Trabajo Fin de Grado de DAM 1º AÑO. Consiste en el desarrollo completo de un sistema para la gestión de un restaurante, incluyendo base de datos, aplicación en Java, interfaz web con HTML/CSS/JS y documentos XML/XSD para el apartado de Lenguaje de Marcas.

---

## Objetivos del Proyecto
- Diseñar y documentar una base de datos funcional para un restaurante.
- Implementar una aplicación en Java que gestione reservas, pedidos y clientes.
- Crear una interfaz web estructurada y accesible.
- Desarrollar documentos XML y su esquema XSD para validar datos del sistema.
- Presentar un proyecto modular, mantenible y bien documentado.

---


---

## Tecnologías Utilizadas
- Java 
- MySQL / MariaDB  
- HTML,CSS,JavaScript  
- XML + XSD  
- Git y GitHub  

---

## Funcionamiento General
El sistema permite gestionar:
- Clientes  
- Reservas  
- Pedidos  
- Productos del menú  
- Facturación básica  

La aplicación Java se conecta a la base de datos y permite realizar operaciones CRUD.  
La parte web muestra la carta del restaurante y elementos visuales del proyecto.  
El XML/XSD valida estructuras de datos relacionadas con pedidos y productos.
