## Informacion
Este módulo contiene la aplicación Java que gestiona la lógica del sistema del restaurante.

---

## Objetivos
- Conectar con la base de datos.  
- Gestionar clientes, reservas, productos y pedidos.  
- Implementar operaciones CRUD.  
- Mantener una arquitectura modular y clara.  

---


## 🛠️ Tecnologías
- Java  
- JDBC  
- MySQL Connector  

---

## 🔌 Conexión a la Base de Datos
El archivo `DBConnection.java` gestiona la conexión mediante JDBC.

---

## Funcionalidades Implementadas
- Consulta de clientes.  
- Gestión de reservas.  
- Gestión de productos y categorías.  
- Creación de pedidos y líneas de pedido.  

---

## ▶Ejecución
1. Importar el proyecto en IntelliJ/Eclipse/Visual Code.  
2. Configurar el archivo de conexión.  
3. Ejecutar `Main.java`.
